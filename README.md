# Trabajo-Pratico-Final
# Sistema de Gestión de Biblioteca Digital

## Descripción

Sistema desarrollado en Python para la administración de una biblioteca digital. La aplicación permite gestionar libros, usuarios y préstamos mediante un enfoque orientado a objetos, implementando conceptos avanzados de programación como herencia, polimorfismo, composición, agregación, decoradores, metaclases y patrones de diseño.

Entre sus principales funcionalidades se encuentran:

* Alta, modificación, baja y listado de libros.
* Alta, modificación, baja y listado de usuarios.
* Registro y devolución de préstamos.
* Consulta de préstamos activos.
* Validación para impedir el préstamo de un libro que ya se encuentra prestado.

## Instrucciones de ejecución

1. Clonar el repositorio:

```bash
git clone https://github.com/Raul-Anriquez/Trabajo-Pratico-Final.git
```

2. Ingresar al directorio del proyecto:

```bash
cd Trabajo-Pratico-Final
```

3. (Opcional) Crear y activar un entorno virtual:

```bash
python -m venv .venv
```

En Windows:

```bash
.venv\Scripts\activate
```

4. Ejecutar la aplicación:

```bash
python Main.py
```

La aplicación se ejecuta en consola y permite acceder a las diferentes funcionalidades mediante un menú interactivo.
